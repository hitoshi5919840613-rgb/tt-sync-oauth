プライバシーポリシー

tt-sync（以下「本ツール」）は、作成者本人だけが使う個人用ツールです。

扱う Google ユーザーデータ

本ツールは Google Calendar API を使い、作成者の Google アカウントにあるカレンダーのうち、作成者が設定で指定したものについて、予定（タイトル・日時・場所・繰り返し・メモ欄）を読み取り、作成・更新します。

使い方

  • データは、別のカレンダーの予定を作成者の Google カレンダーにコピーするためだけに使います。
  • データは作成者のパソコンの中だけで処理・保存します。作成者以外の人や外部のサーバーには送りません。
  • 広告、販売、AI モデルの学習には使いません。
  • 本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

保存と削除

認可の情報は作成者のパソコンのキーチェーンに保存します。作成者は Google アカウントのアクセス権の設定からいつでも認可を取り消せます。取り消した後、本ツールは Google のデータにアクセスできません。
